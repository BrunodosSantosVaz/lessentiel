# Leitor Limpo

Extensão local para ler artigos longos de páginas web e PDFs com menos distrações. O processamento e as preferências ficam no dispositivo; não há conta nem backend.

O MVP está implementado na `develop`, com os nove critérios de aceite verificados em Chromium. A primeira release ainda está em preparação. O ZIP experimental com o leitor habilitado pode ser gerado com `npm run package:test`; instalação, permissões e limitações estão na [Wiki](https://github.com/BrunodosSantosVaz/mla/wiki/Uso-e-instalacao). O pacote normal mantém o recurso desligado enquanto aguarda homologação.
