# L’Essentiel

Extensão Chromium para ler páginas web e PDFs locais, com processamento no dispositivo.

A candidata **0.1.0-rc.2** foi aprovada pelo dono; a promoção estável está em preparação. Esta branch principal recebe primeiro a manutenção dos controles de entrega. O programa continua na branch de release até a publicação pelo fluxo protegido.
